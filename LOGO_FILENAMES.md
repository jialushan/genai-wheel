# Logo filename reference

To replace any tool's logo on the wheel, save a file to `data/logos/`
using the exact filename below, then run `python main.py --render-only`.

**Supported formats**: `.png`, `.svg`, `.jpg`, `.webp`. SVG is preferred
when available (scales cleanly at any size).
